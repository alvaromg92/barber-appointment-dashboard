# Barber Appointment Dashboard

A responsive React dashboard for managing barber shop appointments.

## Features

- Add new appointments
- Search appointments by client name
- Delete appointments
- Appointment summary cards
- Responsive design for desktop and mobile

## Technologies Used

- React
- JavaScript
- CSS
- Vite
- Bootstrap

## Live Demo

https://barber-appointment-dashboard.vercel.app/

## Project Purpose

This project was created as part of my frontend portfolio to practice React state management, form handling, filtering data, and responsive dashboard layouts.
